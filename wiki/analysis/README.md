# Analysis Notes

Use this folder for durable thinking that is not a single company entity page:

| Folder | Use |
|---|---|
| `decisions/` | add/hold/wait/trim decision memos |
| `valuations/` | DCF, fair value, and valuation sensitivity work |
| `earnings/` | earnings transcript digests and quarterly update notes |
| `catalysts/` | news, event, regulation, product, and M&A catalyst notes |
| `comparisons/` | peer comparisons, sector/theme memos, and screener triage |
| `sentiment/` | X/Twitter and market chatter context |
| `audits/` | source integrity audits and source gap registries |

Prefer source-backed bullets and tables over long chat-style prose.
