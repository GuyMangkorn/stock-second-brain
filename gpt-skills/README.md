# GPT Skill Exports

These files are GPT-ready Markdown exports of the local Codex skills in
`.codex/skills/`. Paste a full file into a Custom GPT instruction, Project
instruction, or the first message of a GPT chat.

Each export keeps the original skill workflow and adds shared stock research
rules for source integrity, source priority, current-data freshness, and the
Thai/English language standard.
